# Cognitive Science Syllabus

| Unit | Prerequisites | Ordered lessons | Observable outcomes | Common misconception | Mastery checks |
|---|---|---|---|---|---|
| `COG-B01` Minds as biological, computational, embodied, social, cultural systems | `PSY-B02`, `BIO-I07`, `CSC-B01` | 1. Interdisciplinary mind; 2. brain/body; 3. computation; 4. environment/action; 5. social/cultural scaffolding | Compare levels; construct nonreductive explanations; identify discipline contributions | Interdisciplinary explanation is not merely listing perspectives | ☐ Analyze one cognitive task at five levels; ☐ identify cross-level constraints |
| `COG-B02` Representation, computation, information, levels of analysis | `COG-B01`, `PHI-I02` | 1. Representation criteria; 2. algorithms/process; 3. information; 4. Marr-style levels; 5. dynamical/embodied critiques | Specify task/representation/process/implementation; evaluate representational claims | Neural activity is not automatically a representation | ☐ Formalize cognitive model; ☐ compare representational and dynamical account |
| `COG-I01` Perception, action, attention, predictive processing, embodiment | `COG-B02`, `PSY-B02` | 1. Perceptual inference; 2. active sensing; 3. attention/action loops; 4. predictive models; 5. embodiment/affordance | Model perception-action coupling; evaluate predictive evidence; explain embodiment | Prediction-error language alone does not constitute a tested model | ☐ Analyze sensorimotor task; ☐ compare competing models |
| `COG-I02` Concepts, categories, imagery, memory, reasoning, problem solving | `COG-B02`, `PSY-I03` | 1. Concept theories; 2. categorization; 3. imagery/mental models; 4. memory/reconstruction; 5. reasoning/problem solving | Design discriminating experiments; model concept use; diagnose representation strategy | Categories need not have fixed necessary-and-sufficient definitions | ☐ Test two concept models; ☐ analyze novel problem-solving protocol |
| `COG-I03` Language cognition, acquisition, production, comprehension, bilingualism | `COG-B02`, `LIN-I03` | 1. Acquisition; 2. lexical access; 3. parsing/comprehension; 4. production/dialogue; 5. bilingual control | Interpret language-processing evidence; compare acquisition accounts; analyze bilingual effects | Children do not learn language only by explicit correction/imitation | ☐ Design psycholinguistic experiment; ☐ analyze processing data |
| `COG-I04` Cognitive neuroscience | `COG-I01`, `PSY-I06`, `STA-I03` | 1. Lesion/single-unit; 2. EEG/MEG; 3. fMRI/PET; 4. stimulation/connectivity; 5. reverse inference/multivariate analysis | Choose method by temporal/spatial/causal question; critique neural inference | A colored brain map is not a direct photograph of thought | ☐ Compare methods for question; ☐ audit imaging claim |
| `COG-I05` Computational cognitive modeling | `COG-B02`, `STA-I05`, `AIX-I02` | 1. Symbolic architectures; 2. Bayesian models; 3. neural networks; 4. dynamical models; 5. parameter fitting/model comparison | Implement competing models; fit/compare behavior; connect parameters to theory | Better fit with more flexibility need not mean better explanation | ☐ Reproduce model; ☐ conduct recovery/comparison |
| `COG-I06` Social cognition, culture, development, distributed cognition | `COG-I02`, `SOC-I03`, `PSY-I01` | 1. Theory of mind; 2. joint attention/learning; 3. cultural tools; 4. teams/distributed memory; 5. development/variation | Explain cognition beyond individual skull; analyze cultural scaffolds; compare development | Culture is not external decoration added to universal cognition | ☐ Analyze distributed task; ☐ design cross-cultural study |
| `COG-A01` Consciousness, self, agency, emotion, altered states | `COG-I01`, `COG-I04`, `PHI-I02` | 1. Conscious access; 2. major theories; 3. self/agency; 4. emotion/interoception; 5. sleep/anesthesia/disorders/altered states | Compare theories by predictions; distinguish report/access/phenomenology; interpret state evidence | Neural correlate does not by itself explain or cause consciousness | ☐ Theory-comparison matrix; ☐ analyze consciousness experiment |
| `COG-A02` Comparative, animal, developmental, evolutionary cognition | `COG-I06`, `BIO-B04` | 1. Comparative method; 2. perception/memory/tools; 3. social cognition; 4. infant development; 5. evolutionary inference | Design species-fair tests; distinguish homology/convergence; avoid anthropomorphism/denial | Failure on a human-designed task does not prove absence of capacity | ☐ Critique comparative test; ☐ construct evolutionary account |
| `COG-A03` Human/machine intelligence, architectures, alignment | `COG-I05`, `AIX-A02`, `PHI-A03` | 1. Intelligence definitions; 2. cognitive/AI architectures; 3. benchmarks/generalization; 4. human-AI complementarity; 5. goals/values/alignment | Compare intelligence systems; evaluate benchmarks; design human oversight | Human-like language output does not establish human-like cognitive architecture | ☐ Analyze human/AI task; ☐ build aligned workflow |
| `COG-A04` Cognitive enhancement, neuroethics, societal implications | `COG-A01`, `HLT-A02`, `PHI-I05` | 1. Education/training; 2. drugs/stimulation/interfaces; 3. disability/therapy/enhancement; 4. autonomy/identity/fairness; 5. governance | Evaluate efficacy/ethics; distinguish treatment/enhancement contexts; propose safeguards | “Natural” baseline is not a neutral ethical boundary | ☐ Appraise enhancement evidence; ☐ defend governance policy |
| `COG-E01` Integrative mind and cognition research | `COG-A01`, `COG-A03`, `RSH-E01` | 1. Cross-level question; 2. formal theory; 3. behavioral/neural/computational evidence; 4. model adjudication; 5. open dissemination | Conduct integrative original research; constrain levels mutually; defend explanatory scope | Collecting multiple modalities is not integration without shared predictions | ☐ Complete multimethod thesis; ☐ pass cross-disciplinary defense |
