# Systems Science Syllabus

| Unit | Prerequisites | Ordered lessons | Observable outcomes | Common misconception | Mastery checks |
|---|---|---|---|---|---|
| `SYS-B01` Systems, boundaries, stocks, flows, state, environment, and scale | `FND-B03`, `MAT-B06` | 1. Whole/parts/relations; 2. purpose and boundary; 3. stock/flow/state; 4. input/output/environment; 5. scale and hierarchy | Define system models; choose boundaries; distinguish stock from rate | System boundaries are analytical choices, not always natural lines | ☐ Model two real systems; ☐ justify inclusions/exclusions |
| `SYS-B02` Causal loops, feedback, delay, accumulation, and consequences | `SYS-B01`, `LOG-I05` | 1. Causal links/polarity; 2. reinforcing/balancing loops; 3. delays and oscillation; 4. accumulation/nonlinearity; 5. policy resistance | Draw valid loop diagrams; predict qualitative behavior; locate unintended effects | A loop diagram is not proof of causal magnitude or timing | ☐ Explain observed behavior by loops; ☐ propose discriminating evidence |
| `SYS-I01` System dynamics, differential/difference models, simulation | `SYS-B02`, `MAT-I07`, `CSC-B03` | 1. Stock-flow equations; 2. discrete/continuous time; 3. feedback model construction; 4. simulation/calibration; 5. sensitivity and policy tests | Translate diagrams to equations; simulate/validate; compare policies | Fitting historical behavior does not uniquely validate structure | ☐ Build calibrated model; ☐ conduct structural sensitivity tests |
| `SYS-I02` Networks | `SYS-B01`, `MAT-I01`, `STA-B03` | 1. Nodes/edges/directed/weighted; 2. degree/path/community/centrality; 3. random/small-world/scale-free models; 4. diffusion/contagion; 5. robustness/intervention | Calculate network measures; model diffusion; select intervention points | High centrality has multiple definitions and not always influence | ☐ Analyze an empirical network; ☐ test diffusion/intervention scenarios |
| `SYS-I03` Control, stability, observability, adaptation, and cybernetics | `SYS-I01`, `MAT-I06` | 1. Plant/controller/reference; 2. open/closed loop; 3. stability and response; 4. controllability/observability; 5. adaptive control and requisite variety | Analyze feedback control; tune basic controller; assess state inference | More feedback/gain can destabilize a delayed system | ☐ Model and stabilize a system; ☐ diagnose overshoot/instability |
| `SYS-I04` Emergence, self-organization, nonlinear dynamics, and complexity | `SYS-I01`, `SYS-I02` | 1. Micro rules/macro patterns; 2. nonlinearity and phase space; 3. bifurcation/chaos; 4. self-organization; 5. complexity measures and limits | Demonstrate emergence; analyze nonlinear regimes; avoid invalid reduction | “Emergent” does not mean inexplicable or supernatural | ☐ Reproduce emergent pattern; ☐ connect macro behavior to mechanisms |
| `SYS-I05` Risk, uncertainty, resilience, redundancy, and failure propagation | `SYS-I02`, `STA-I05` | 1. Hazard/exposure/consequence; 2. aleatory/epistemic uncertainty; 3. fault trees and cascades; 4. redundancy/diversity/modularity; 5. resilience and recovery | Model failures; quantify uncertainty; design resilient architecture | Redundancy sharing a common failure mode is fragile | ☐ Complete fault/cascade analysis; ☐ validate resilience intervention |
| `SYS-I06` Decision theory, utility, information, and multi-criteria choice | `STA-I05`, `MAT-A05`, `PHI-I01` | 1. Acts/states/outcomes; 2. expected utility and risk attitude; 3. Bayesian decisions; 4. value of information; 5. multi-criteria and robust choice | Build decision models; calculate information value; expose value judgments | A numerical score does not make value trade-offs objective facts | ☐ Analyze a consequential decision; ☐ test sensitivity to probabilities/values |
| `SYS-A01` Game theory, mechanism design, and collective action | `SYS-I06`, `ECO-I02` | 1. Strategic/normal games; 2. Nash and mixed strategies; 3. sequential/repeated games; 4. incomplete information; 5. mechanisms, commons, cooperation | Solve equilibria; predict strategic responses; design incentive-compatible rules | Equilibrium is not necessarily fair, efficient, unique, or observed | ☐ Solve representative games; ☐ design/test a mechanism |
| `SYS-A02` Operations research, scheduling, queues, inventory, logistics | `SYS-I06`, `MAT-A05` | 1. Linear/integer programs; 2. networks/routing; 3. queues/capacity; 4. inventory/stochastic operations; 5. scheduling/simulation | Formulate operational models; solve and interpret; evaluate bottlenecks | Optimizing a local metric can degrade system performance | ☐ Optimize a realistic operation; ☐ stress-test assumptions |
| `SYS-A03` Agent-based modeling, cellular automata, evolutionary systems | `SYS-I04`, `CSC-I03` | 1. Agents/rules/environment; 2. cellular automata; 3. interaction and emergence; 4. evolutionary selection/replication; 5. calibration/validation/experiments | Implement ABMs; connect rules to patterns; analyze stochastic robustness | A plausible animation is not a validated explanation | ☐ Reproduce and vary a model; ☐ validate against independent patterns |
| `SYS-A04` Scenario analysis, forecasting, foresight, and deep uncertainty | `SYS-I05`, `STA-A02` | 1. Forecast target/base rate; 2. trend/model/judgment ensembles; 3. scenarios and drivers; 4. deep uncertainty/robust decisions; 5. horizon scanning and update | Produce calibrated forecasts; construct coherent scenarios; choose robust actions | Scenarios are not predictions, and precision does not guarantee accuracy | ☐ Maintain scored forecasts; ☐ build decision-relevant scenario set |
| `SYS-A05` Systems intervention, leverage, governance, and evaluation | `SYS-B02`, `SYS-I06`, `RSH-A01` | 1. Problem/system framing; 2. leverage points and behavior; 3. stakeholder/power/governance; 4. intervention portfolio; 5. monitoring, adaptation, exit | Design ethical interventions; anticipate adaptation; evaluate system-level effects | A high leverage point can be politically or operationally inaccessible | ☐ Produce intervention theory; ☐ evaluate unintended distributional effects |
| `SYS-E01` Complex adaptive systems research and transdisciplinary synthesis | `SYS-A03`, `SYS-A04`, `SYS-A05` | 1. Multi-level question; 2. cross-domain concepts and commensurability; 3. model ensemble/mixed evidence; 4. stakeholder co-production; 5. reflexive synthesis | Integrate disciplines without erasing methods; produce actionable uncertain knowledge | Shared vocabulary can hide incompatible assumptions | ☐ Complete transdisciplinary study; ☐ defend integration to domain experts/stakeholders |
