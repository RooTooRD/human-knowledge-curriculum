# Architecture and Design Syllabus

| Unit | Prerequisites | Ordered lessons | Observable outcomes | Common misconception | Mastery checks |
|---|---|---|---|---|---|
| `ARC-B01` Design problems, users, context, affordance, function, form, iteration | `ENG-B01`, `ART-B01` | 1. Problem/need; 2. user/context; 3. affordance/function; 4. form/constraint; 5. iteration/critique | Frame design problem; observe users; generate/test alternatives | Design is not decoration applied after function | ☐ Produce tested concept set; ☐ defend problem framing |
| `ARC-B02` Sketching, diagramming, prototyping, critique, visual hierarchy | `ARC-B01`, `ART-B02` | 1. Exploratory sketch; 2. systems/flow diagram; 3. physical/digital prototype; 4. hierarchy/presentation; 5. critique/revision | Externalize ideas; prototype at fitting fidelity; use critique diagnostically | Polished prototypes too early can suppress exploration | ☐ Iteration portfolio; ☐ revise from user/peer critique |
| `ARC-I01` Human-centered research, accessibility, ergonomics, inclusive design | `ARC-B02`, `PSY-B02`, `RSH-I06` | 1. User research; 2. task/journey; 3. anthropometry/ergonomics; 4. disability/accessibility; 5. participation/testing | Conduct ethical research; design for diverse bodies/abilities; validate usability | “Average user” designs systematically exclude real variation | ☐ Accessibility-tested prototype; ☐ research-to-requirement trace |
| `ARC-I02` Product, service, information, and interaction design | `ARC-I01`, `CSC-I11` | 1. Product form/use; 2. service blueprint; 3. information architecture; 4. interaction/state/feedback; 5. lifecycle/metrics | Design coherent cross-channel experience; specify states; evaluate outcomes | A screen interface is only one component of a service system | ☐ Deliver service/product prototype; ☐ pass task tests |
| `ARC-I03` Architectural space, program, structure, envelope, materials, light, climate, construction | `ARC-B02`, `ENG-I01`, `ECS-B03` | 1. Site/program; 2. space/circulation; 3. structure/material; 4. envelope/daylight/climate; 5. construction/detail | Develop integrated building concept; resolve program/structure/climate; communicate drawings/models | Striking form cannot compensate for unsafe, unusable, unbuildable space | ☐ Complete building studio; ☐ technical/environmental review |
| `ARC-I04` Global architectural history | `ARC-B01`, `ART-I02`, `HST-I01` | 1. Vernacular/ancient; 2. Islamic/Asian/African/Indigenous; 3. medieval/early modern; 4. industrial/modern; 5. colonial/postcolonial/contemporary | Analyze buildings in climate/culture/power; compare types; trace exchange | Architectural modernity is not one style diffusing unchanged from Europe | ☐ Comparative building atlas; ☐ contextual precedent analysis |
| `ARC-I05` Urban design | `ARC-I03`, `GEO-B04` | 1. Block/street/public realm; 2. density/mix; 3. land use/housing; 4. mobility/infrastructure; 5. place/community | Analyze urban form; design accessible public realm; integrate mobility/housing | Wider roads can induce traffic rather than permanently cure congestion | ☐ Neighborhood plan; ☐ accessibility/stakeholder evaluation |
| `ARC-I06` Landscape architecture, ecology, water, agriculture, public space | `ARC-I03`, `ECS-I01` | 1. Site/terrain/soil; 2. plants/ecology; 3. water/stormwater; 4. food/productive landscapes; 5. public space/maintenance | Design living systems; manage water; plan succession/maintenance | Landscapes are dynamic systems, not static visual backgrounds | ☐ Landscape plan/model; ☐ seasonal/water performance test |
| `ARC-I07` Design systems, typography, grids, branding, communication | `ARC-B02`, `COM-I04` | 1. Type/readability; 2. grid/layout; 3. identity/brand; 4. component/design system; 5. accessibility/governance | Build coherent visual system; design readable information; document reusable rules | Consistency without hierarchy/context can reduce usability | ☐ Deliver accessible identity/system; ☐ cross-medium application |
| `ARC-A01` Sustainable, bioclimatic, circular, resilient buildings/settlements | `ARC-I03`, `ARC-I06`, `ENG-A03` | 1. Passive climate design; 2. energy/daylight; 3. water/material lifecycle; 4. adaptation/resilience; 5. post-occupancy performance | Simulate environmental performance; reduce lifecycle impact; design for change | A “green” feature does not ensure whole-building sustainability | ☐ Net-performance design; ☐ lifecycle/resilience defense |
| `ARC-A02` Codes, procurement, ethics, preservation, participation | `ARC-I03`, `LAW-I03`, `COM-A03` | 1. Code/zoning/access; 2. contracts/procurement; 3. professional duty; 4. preservation/adaptive reuse; 5. participation/conflict | Navigate approvals; choose delivery; balance heritage/community/safety | Public consultation is not meaningful if decisions are already closed | ☐ Approval/procurement dossier; ☐ facilitated community review |
| `ARC-A03` Computational design, simulation, fabrication, smart environments | `ARC-I02`, `ENG-I04`, `MAT-A04` | 1. Parametric rules; 2. optimization/simulation; 3. BIM/data; 4. digital fabrication/robotics; 5. sensors/adaptive space | Build parametric model; fabricate accurately; validate smart-system value/privacy | Computational complexity is not design quality | ☐ Fabricated computational prototype; ☐ simulation-to-test validation |
| `ARC-A04` Integrated research-design-build or urban intervention | `ARC-A01`, `ARC-A02`, `ENG-A05` | 1. Partner/site research; 2. brief/co-design; 3. technical development; 4. build/implementation; 5. post-occupancy/evaluation | Deliver responsible real intervention; coordinate disciplines; measure use/performance | Completion photographs do not establish social or environmental success | ☐ Built/implemented project; ☐ post-occupancy report |
| `ARC-E01` Original architectural or design research | `ARC-A03`, `ARC-A04`, `RSH-E01` | 1. Original design question; 2. precedent/theory; 3. experiment/prototype; 4. performance/experience evidence; 5. exhibition/publication | Produce original design knowledge; connect artifact to evidence; state transfer limits | A unique object is not research unless it answers a generalizable or critically significant question | ☐ Thesis/artifact; ☐ expert/community defense |
