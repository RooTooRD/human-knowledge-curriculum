# Linguistics Syllabus

| Unit | Prerequisites | Ordered lessons | Observable outcomes | Common misconception | Mastery checks |
|---|---|---|---|---|---|
| `LIN-B01` Human language, diversity, description, prescription, myths | `FND-B01`, `SOC-B01` | 1. Language/design features; 2. grammar/lexicon/use; 3. spoken/signed modalities; 4. diversity/universals; 5. description/prescription/myths | Identify linguistic patterns; distinguish descriptive and social standards; refute myths | Nonstandard dialects are systematic, not broken language | ☐ Analyze unfamiliar language data; ☐ evidence-based myth rebuttal |
| `LIN-B02` Speech sounds, articulation, transcription, sign modality | `LIN-B01`, `FND-B03` | 1. Vocal tract; 2. consonants; 3. vowels; 4. IPA/acoustics; 5. sign parameters/modality | Produce/transcribe sounds; read spectrogram basics; compare spoken/signed form | Letters are not sounds, and sign languages are not manual encodings of spoken language | ☐ IPA practical; ☐ analyze sound/sign contrasts |
| `LIN-I01` Phonology | `LIN-B02`, `MAT-B08` | 1. Phoneme/allophone; 2. features/natural classes; 3. rules/processes; 4. syllable/stress/tone; 5. constraint/representation theories | Discover contrasts/distributions; write analyses; compare rule/constraint accounts | Minimal pairs diagnose contrast but absence of one does not prove no contrast | ☐ Solve phonology datasets; ☐ defend representation |
| `LIN-B03` Words, morphemes, formation, lexical structure | `LIN-B01`, `FND-B06` | 1. Word/morpheme/allomorph; 2. inflection/derivation; 3. compounding/other formation; 4. morphological typology; 5. lexical relations/productivity | Segment/analyze words; compare typologies; predict productive patterns | A written space does not universally define a linguistic word | ☐ Analyze morphology dataset; ☐ construct lexicon/rules |
| `LIN-I02` Syntax | `LIN-B03`, `LOG-I03` | 1. Category/constituency; 2. phrase/dependency structure; 3. argument/valency; 4. agreement/case/order; 5. movement/recursion/variation | Diagnose constituents; build trees/dependencies; compare analyses | Word order alone does not determine syntactic function | ☐ Solve syntax dataset; ☐ defend tree with diagnostics |
| `LIN-I03` Semantics | `LIN-I02`, `LOG-I03` | 1. Reference/predication; 2. entailment/truth conditions; 3. compositionality; 4. quantification/scope; 5. lexical meaning/event semantics | Derive sentence meanings; test entailment; resolve scope readings | Meaning is not a bag of word definitions | ☐ Complete semantic derivations; ☐ analyze ambiguity |
| `LIN-I04` Pragmatics and discourse | `LIN-I03`, `COM-B02` | 1. Context/deixis; 2. implicature/cooperation; 3. presupposition; 4. speech acts/politeness; 5. discourse/coherence/conversation | Infer context-dependent meaning; distinguish entailment/implicature/presupposition; analyze interaction | What is conveyed need not be literally encoded | ☐ Annotate dialogue; ☐ design tests for inference type |
| `LIN-I05` Sociolinguistics | `LIN-B01`, `SOC-B03` | 1. Variation/change; 2. dialect/register/style; 3. identity/community; 4. multilingualism/contact; 5. policy/power/discrimination | Analyze variation quantitatively/socially; explain code choice; critique language prejudice | Accent does not measure intelligence or grammatical competence | ☐ Conduct variation study; ☐ produce language-policy analysis |
| `LIN-I06` Acquisition, processing, literacy, psycholinguistics | `LIN-I02`, `PSY-B02` | 1. Child acquisition; 2. lexical/sentence processing; 3. production/error; 4. reading/writing; 5. multilingual processing/disorder orientation | Interpret acquisition/processing data; design experiments; distinguish competence/performance | Children do not acquire grammar by imitation alone | ☐ Analyze child/processing corpus; ☐ design experiment |
| `LIN-I07` Historical linguistics | `LIN-I01`, `LIN-I02`, `HST-B02` | 1. Sound change; 2. analogy/grammaticalization; 3. comparative method; 4. families/reconstruction; 5. contact/borrowing | Establish correspondence; reconstruct forms; distinguish inheritance/borrowing | Similar-looking words alone do not prove genetic relation | ☐ Complete reconstruction; ☐ justify family/contact inference |
| `LIN-I08` Writing systems, corpus, lexicography, translation, interpretation | `LIN-B03`, `RSH-I01` | 1. Script types/orthography; 2. corpus design/concordance; 3. dictionary construction; 4. translation equivalence/strategy; 5. interpreting/ethics | Analyze scripts/corpora; build lexical entry; justify translation | Word-for-word translation is not automatically faithful | ☐ Corpus/lexicon project; ☐ annotated translation |
| `LIN-A01` Typology, universals, formal grammars, competing theories | `LIN-I01`, `LIN-I02`, `LIN-I03` | 1. Sampling/typology; 2. universals/implicational patterns; 3. generative formalisms; 4. functional/cognitive approaches; 5. theory comparison | Evaluate typological evidence; formalize grammar; compare predictions | Absence in a language sample does not prove impossibility | ☐ Crosslinguistic analysis; ☐ formal theory comparison |
| `LIN-A02` Computational linguistics, speech, NLP, language models | `LIN-I08`, `CSC-I02`, `AIX-A02` | 1. Text/speech preprocessing; 2. tagging/parsing; 3. semantics/retrieval; 4. translation/speech; 5. LMs/evaluation/bias | Build NLP pipeline; evaluate across languages; connect errors to linguistic structure | Benchmark performance in dominant languages does not imply universal language competence | ☐ Implement/evaluate NLP system; ☐ multilingual bias audit |
| `LIN-A03` Documentation, revitalization, field methods, ethics | `LIN-I05`, `LIN-I07`, `RSH-I06` | 1. Community goals/consent; 2. elicitation/recording; 3. transcription/annotation; 4. grammar/dictionary/archive; 5. revitalization/ownership | Create high-quality documentation collaboratively; archive sustainably; support community priorities | Documentation owned only by researchers can reproduce extraction | ☐ Produce community-reviewed deposit; ☐ design revitalization resource |
| `LIN-E01` Linguistic research and theory | `LIN-A01`, `LIN-A03`, `RSH-E01` | 1. Original pattern/question; 2. data/language sample; 3. analysis/theory; 4. alternatives/reproducibility; 5. publication/community return | Produce original linguistic analysis; adjudicate theories; share data ethically | A novel dataset is not sufficient without accurate analysis and community responsibility | ☐ Complete thesis/data; ☐ pass theoretical/community defense |
