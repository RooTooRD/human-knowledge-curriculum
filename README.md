# The Human Knowledge Curriculum

The Human Knowledge Curriculum is a dependency-driven, lifelong answer to the question:
**What should an educated person know?** It is not a university degree. It is a public
map for self-education from ordinary literacy and numeracy to advanced disciplinary
study, integrative judgment, and original inquiry.

> [!IMPORTANT]
> The curriculum is a carefully specified educational proposal, not a credential or a
> guarantee of mastery after fixed hours. Clinical, legal, hazardous, and
> professionally regulated work requires qualified supervision and local authorization.

Every unit has a stable ID, difficulty, Core or Extension status, exact prerequisites,
lessons, observable outcomes, misconceptions, mastery checks, resources, terminology,
project contribution, assessment, time budget, and review plan.

## How the corpus is organized

```text
Curriculum/
├── README.md                  public curriculum index
├── global-graph.md            cross-domain dependency backbone
├── pathways.md                10-, 15-, and 20-year routes
├── specializations.md         twelve Extension paths
├── connection-atlas.md        all 741 discipline pairs
└── <Discipline>/
    ├── README.md              twelve-section subject portal
    ├── roadmap.md             knowledge graph and prerequisites
    ├── syllabus.md            lessons, outcomes, misconceptions, mastery
    ├── resources.md           edition-specific resources
    ├── glossary.md            unit terminology
    ├── projects.md            four project scales
    ├── assessment.md          unit-level mastery evidence
    ├── schedule.md            hours and review allocation
    └── connections.md         links to all other disciplines
```

In prose: the root explains the project; global files define common architecture and
routes; each discipline portal joins eight detailed learning artifacts through the
same stable unit IDs; the atlas supplies one canonical explanation for every pair of
disciplines.

The structural validators can establish completeness and internal consistency. They
cannot establish real-world learning effectiveness, assessment validity, resource
accessibility, or universal hour requirements. Those questions require the transparent
learner evidence described in the evaluation protocol.

## Six phases

| Phase | Result |
|---:|---|
| 1 | Acyclic global and disciplinary knowledge graph |
| 2 | Complete lessons, outcomes, misconceptions, and mastery checks |
| 3 | Resources and glossaries mapped to every unit |
| 4 | Projects and criterion-referenced assessments |
| 5 | Unit hours, spaced review, lifelong pathways, and specializations |
| 6 | Public navigation, cross-disciplinary atlas, editorial governance, accessibility, and evaluation |
